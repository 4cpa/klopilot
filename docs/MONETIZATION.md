# Nutzen, Zweck & Monetarisierung — klopilot.ch

## Teil 1 · Nutzen & Zweck

### 1.1 Mission

Förderung der **Notwendigkeit frei zugänglicher Toilettenanlagen weltweit**.
Eine Toilette ist Grundinfrastruktur — wie ein Trinkbrunnen oder eine Sitzbank.
klopilot macht sichtbar, wo es welche gibt, wie gut sie sind und wo sie fehlen.

### 1.2 Wer profitiert wovon

| Zielgruppe | Konkreter Nutzen |
|---|---|
| **Reisende & Touristen** | Schnell finden, wo eine saubere Toilette ist — überall auf der Welt |
| **Eltern mit Kindern** | Filter "kinderfreundlich" mit Wickeltisch-Hinweis |
| **Menschen mit Behinderung** | Verlässliche Barrierefreiheits-Information aus der Community |
| **Schwangere, ältere Menschen, chronisch Kranke (z. B. Reizdarm, Crohn)** | Planungssicherheit im Alltag |
| **LGBTQ+** | Inklusivitäts-Bewertung als Sicherheitsfaktor |
| **Radler, Wanderer, Outdoor-Sportler** | Pausen-Planung jenseits von Gastro |
| **Stadtverwaltungen** | Datenbasis für Investitionsentscheidungen |
| **NGOs (z. B. WASH-Initiativen)** | Sichtbarmachung weltweiter Versorgungslücken |
| **Partnerbetriebe ("Nette Toilette")** | Werben mit Gastfreundschaft |
| **Tourismusverbände** | Service-Qualität messbar machen |
| **Forschung** | Anonymisierte Daten für urbane Hygiene-Studien |

### 1.3 Gesellschaftlicher Nutzen

- **Würde:** Toilettenzugang ist ein Menschenrechtsthema (UN SDG 6).
- **Inklusion:** Wer keine zuverlässige Toilette findet, ist im öffentlichen
  Raum eingeschränkt.
- **Hygiene & Public Health:** Bewertete, sichtbare Toiletten werden besser
  unterhalten.
- **Daten als Hebel:** "Toiletten-Wüsten"-Heatmap macht Lücken zum politischen
  Argument.

### 1.4 Was klopilot **bewusst nicht** ist

- Kein Bewertungs-Pranger: konstruktive Kritik (auch via Fliegen) ist erwünscht,
  Beleidigungen werden moderiert.
- Kein Werbe-Kanal an Endnutzer.
- Keine Datensammlung über Nutzer-Bewegungsprofile.
- Kein Ersatz für barrierefreie Auskunfts-Pflichten von Betreibern — eher
  Ergänzung.

## Teil 2 · Monetarisierung

### 2.1 Grundprinzip

> **Endnutzer zahlen niemals.** Werbung an Endnutzer ist ausgeschlossen.
> Nutzer-Daten werden nicht verkauft. Einnahmen entstehen aus B2B-Beziehungen,
> Lizenzen und Mission-aligned Förderung.

### 2.2 Einnahmequellen (priorisiert)

#### A — Partnerprogramm "Nette Toilette" (B2B, ab P3)

**Was:** Gastronomie, Hotels, Tankstellen, Geschäfte zahlen einen kleinen
Jahres-Beitrag, um auf der Karte als offizieller Partner mit Badge sichtbar zu
sein. Sie öffnen ihre Toiletten kostenfrei für Passanten.

- **Modell:** Tiered Subscription (z. B. CHF 120 / Jahr Solo, CHF 480 / Jahr
  Filialkette mit ≤ 10 Standorten, individuell für grössere Ketten).
- **Was Partner bekommen:** Badge auf Karte, eigener Eintrag mit Öffnungs-
  zeiten, Rückkanal an Bewertungen, Self-Service-Statistik (anonymisiert).
- **Was sie nicht bekommen:** keine Beeinflussung der Bewertung, keine
  versteckten Vorteile, keine Endnutzer-Daten.

Vorbild: Das deutsche "Nette Toilette"-Modell, in dem Kommunen Gastronomen
einen kleinen Zuschuss zahlen, damit Passanten gratis aufs WC dürfen. klopilot
digitalisiert und internationalisiert dieses Konzept.

#### B — Öffentliche Auftraggeber (B2G, ab P3)

**Was:** Stadtverwaltungen, Tourismusbüros, Verkehrsbetriebe lizenzieren
strukturierte Daten und/oder den eingebetteten Karten-Layer.

- **Modell:** Jahresvertrag oder API-Volumen-Tarif. Beispiel: CHF 5 000 /
  Jahr für eine mittelgrosse Stadt mit Karten-Embed und Daten-Feed.
- **Mehrwert:** Verwaltung sieht Versorgungslücken, plant gezielt.
- **Mission-Boost:** Erlöse fliessen in den weiteren Aufbau.

#### C — Open-Data-Lizenz mit Premium-Tier (ab P4)

- Basis-Daten zu öffentlichen Toiletten unter **CC-BY 4.0** kostenlos.
- **Premium-API** (Echtzeit-Updates, höhere Rate-Limits, SLA, eigene Felder)
  kostenpflichtig für kommerzielle Nutzer (z. B. Reise-Apps, Navi-Anbieter).

#### D — Anonymisierte Insights für Forschung & Beratung (ab P4)

- Aggregierte, anonymisierte Reports zu urbaner Toiletten-Versorgung,
  Sauberkeits-Trends, Barrierefreiheits-Quoten.
- Nur aggregiert, nie personenbezogen, mit DPIA und Ethik-Review.
- Käufer: Universitäten, Beratungen, NGOs, Behörden.

#### E — Sponsoren & Stiftungen (laufend)

- Mission-aligned Sponsoring durch Hersteller von Sanitärbedarf, Hygiene,
  WASH-Stiftungen, Smart-City-Initiativen.
- **Klare Trennung:** Sponsoring wird als solches gekennzeichnet, beeinflusst
  keine Bewertungen.
- Optional: gemeinnützige Stiftung "klopilot Foundation" als Träger der
  Heatmap-Mission und Open-Data-Initiative.

#### F — White-Label / Embedding (ab P4)

- Tourismusregionen, Festivals, Veranstalter können einen White-Label-Layer
  einbetten ("Toiletten beim Open Air XY") gegen Lizenzgebühr.

### 2.3 Was wir explizit **ausschliessen**

| Modell | Status |
|---|---|
| Display-Werbung an Endnutzer | **nein** |
| Native Ads / "Sponsored Toilet" | **nein** |
| Verkauf von Standortdaten | **nein** |
| Verkauf von Nutzer-Profilen | **nein** |
| Premium-Account für Endnutzer mit Vorteilen bei Bewertungen | **nein** |
| Pay-to-Play (bezahlte bessere Sichtbarkeit einer Toilette) | **nein** |
| Affiliate-Links zu Drogerieartikeln o. ä. | **nein** |

### 2.5 Governance

- Finanztransparenz: Jahresreport mit Einnahmenstruktur (anonymisiert) für
  Community.
- Beirat aus Mission-Stakeholdern (NGO, Stadt, Forschung) ab P4.
- Re-Investitionspflicht: ≥ 50 % Überschuss in Mission (Heatmap, Open Data,
  Erschliessung unterversorgter Regionen).
