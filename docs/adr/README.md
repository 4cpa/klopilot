# Architecture Decision Records (ADRs)

Dieses Verzeichnis dokumentiert wesentliche Architektur- und Produktentscheide
für klopilot.ch. Jeder ADR hält **Kontext**, **Entscheidung** und **Konsequenzen**
fest — bewusst kurz, damit spätere Mitwirkende das _Warum_ nachvollziehen können.

## Format

```
docs/adr/NNNN-kurzer-titel.md
```

Status eines ADR: `Vorgeschlagen` · `Akzeptiert` · `Abgelöst durch ADR-XXXX`.
Ein einmal akzeptierter ADR wird nicht umgeschrieben, sondern bei Bedarf durch
einen neuen ADR abgelöst.
